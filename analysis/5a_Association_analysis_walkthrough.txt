### ASSOCIATION ANALYSIS WALKTHROUGH

## =============================== 1. Generate input files ===============================

The association analysis takes in tables of minor allele counts for each pseudo-chromosome,
a list of trait values (in this case, mitotype), a list of samples, and a genetic distance matrix.
The genetic distance matrix was automatically generated within the ANGSD variant calling pipeline,
and the trait values were mitotype. To generate the table of minor allele counts:
	
# 	(A) Split .geno file into manageable chunks, or "pseudo chromosomes"
#		First find the number of lines (SNPs) in the geno file and divide by 25 (25 is an arbitrary number I chose)
$ wc -l cz_snps.geno

#	(B) Create 25 geno files each with 1079544 SNPs
$ split -l 1079544 cz_snps.geno cz_snps.geno

#	(C) Manually change the silly "ab", "ac", etc in the file names to to "01", "02", etc.

#	(D) Make postAlleles files
$ for GF in cz_snps.geno*; do
$ 	awk "{ printf \$1\"\\t\"\$2; for(i=4; i<=NF-1; i=i+3) { i2=i+1; printf \"\\t\"\$i+2*\$i2} ; printf \"\\n\";}" $GF > chr${GF/cz_snps.geno/}.postAlleles
$ done

#	(E) Change tabs to spaces
$ for i in *postAlleles; do
$ 	expand -t1 $i > output/$i
$ done


## =========================== 2. Run the association analysis ===========================

Params:
	gt				Table of minor allele counts (*.postAlleles from step 1)
	traits			Table of traits, "mitogroup.txt"
	gdist.samples	Table of samples, "samples.txt"
	gdist			Table of genetic distances, "cz_snps.ibsMat"

Params left to default setting:
	badsites=0			No 'bad' sites excluded.
	hold.out=0			Holdout analysis not conducted.
	plots=TRUE			Plots generated for initial data visualization.			
	nsites=5500000		For FDR correction; we left this as default because p-values weren't used in our analysis.
	prune.dist=50000	Window size for linkage disequilibrium pruning.

For a given pseudo-chromosome, the following was run:
`Rscript RDA_GWAS_marshall_2022.R gt=chr01.postAlleles traits=mitogroup.txt gdist.samples=samples.txt gdist=cz_snps.ibsMat`

The analysis was run on a cluster using a slurm scheduler; the individual pseudo-chromosome
lines can be found in "gwas" and the slurm script is "gwas.slurm". The script that was run 
for each pseudo-chromosome is "RDA_GWAS_marshall_2022.R". It is a modified version of the 
script available here:
https://github.com/z0on/Multivariate_GWAS


## ================================ 3. Process the results ================================

Run the `GWAS_processing.R` script.

Output:              An RData bundle containing results table for pruned SNPs (gwas) with zscores, pvalues, 
                     betas and R2, their genotypes (gt.s), genotypes of hold-out samples (if any) at the selected
                     SNPs (gt.test), manhattan plot data for all sites (manh), and sample scores 
                     in the ordination (sample.scores).
